# Private macOS text release foundation

Create an isolated, fixed macOS arm64 packaging path for the shared local web workbench. Its immutable launcher profile accepts only UTF-8 Markdown/text and uses the existing writer. PDF/OCR/document engines and models are excluded pending separate review. Preserve existing local development web work.

Require complete project legal documents and exact dependency notices before packaging. Record versions, metadata/RECORD hashes, native Python provenance, frozen sources and artifact hashes. Output a local candidate only; no GitHub changes, publishing or claim of complete legal approval.
